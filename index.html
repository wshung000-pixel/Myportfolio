資料清單

CSV 匯入

使用本 App 標準 CSV 格式；其他金融機構原始格式需先建立對應解析器，不能直接假設欄位相同。

欄位：account,kind,symbol,name,currency,quantity,cost,price。可先下載範本。

Firstrade App 庫存截圖匯入（測試版）

可一次選取最多 8 張截圖，僅在此裝置瀏覽器進行 OCR 文字辨識，不將圖片儲存於 GitHub 或 Firestore。辨識引擎由外部 CDN 載入。

請先選擇圖片。

先偵測持股分隔線，再逐列分開辨識：代號與股數／單位成本／總成本，並驗算後預覽；辨識不完整可點「新增一列」自行補入。請逐筆核對！

代碼股數每股成本 (USD)總成本 (USD)操作

僅新增不存在的代碼，既有持股不會覆蓋。圖片中可能包含帳號與財務資料，請勿將截圖上傳至公開 GitHub。

Firstrade 交易紀錄分析（V1.6）

上傳 Firstrade 官方活動 CSV，預覽買賣交易估算股數及與現有持股的差異。僅在瀏覽器分析，不會修改資產。

Firstrade 持股 CSV 匯入

僅適用具有 Symbol、Quantity、Average Cost 等欄位的持股庫存 CSV。交易活動報表不適用。請仔細核對預覽。

只新增未存在的股票；既有資料略過，不自動刪除。CSV 僅在本機瀏覽器解析。

行情更新

上市台股使用 GitHub Actions 取得臺灣證交所公開收盤行情，網站讀取同網域快取；第一次必須先成功執行排程。資料未更新時不覆蓋舊價格。

美股收盤價為非即時參考資料，僅支援目前公開清單涵蓋的代號。

匯出備份

備份可能包含金融資料，請自行加密保存；勿提交至 GitHub。

匯率

V1.0 先手動設定匯率。下一版可由後端排程取得匯率與美股行情。

資料安全

你的 Firebase UID（只用於設定本人專用權限）

資料僅允許登入者在自己的 UID 路徑下存取；請務必部署附帶的 Firestore 規則，並將 Firebase Authentication 授權網域設定為你的正式網址。
